02 · Dataset & Preprocessing

Data Pipeline

The Kaggle Chest X-Ray Pneumonia dataset consists of 5,856 frontal-view radiographs from pediatric patients aged 1-5 years, collected at Guangzhou Women and Children's Medical Center, China.

Image Normalization

All images resized to 224×224 pixels to match ImageNet pre-training dimensions. Pixel values normalized using ImageNet statistics:

  • Mean: [0.485, 0.456, 0.406] (RGB channels)
  • Std: [0.229, 0.224, 0.225] (RGB channels)
Data Augmentation

Applied exclusively during training to increase model robustness:

  • Random horizontal flips (p=0.5) - anatomically valid for chest X-rays
  • Random rotation (±10°) - simulates minor positioning variations
  • Random brightness/contrast adjustment - accounts for imaging equipment variability
  • No vertical flips - anatomically invalid for chest radiographs
Class Imbalance Handling

Dual-level strategy to address 3:1 pneumonia-to-normal ratio:

  • Sampling Level: WeightedRandomSampler with inverse class frequency weights
  • Loss Level: Focal Loss with α=0.75 (favoring normal class) and γ=2.0
  • Rationale: Combined approach prevents model from predicting majority class trivially

Dataset Limitations & Mitigation

The dataset is constrained to a single institution (Guangzhou Women and Children's Medical Center) and a narrow age range (1-5 years), potentially limiting generalizability to adult populations and different imaging protocols. Future work should validate on multi-institutional cohorts with diverse demographics and equipment manufacturers. Additionally, the dataset provides only binary labels (normal vs. pneumonia) without distinguishing bacterial from viral etiology, which would be clinically valuable for targeted antibiotic therapy.

DenseNet121 + CBAM

A hybrid architecture combining DenseNet121's feature reuse efficiency with Convolutional Block Attention Module's sequential channel and spatial attention mechanisms.

DenseNet121 Backbone

Architecture: Four dense blocks with growth rate k=32, resulting in 8M parameters (vs. 25.6M for ResNet50). Each dense block uses concatenation-based feature propagation.

Key Properties:

  • Feature reuse through direct connections between all layers
  • Reduced parameter count through bottleneck layers (1×1 convolutions)
  • Improved gradient flow enabling deeper network training
  • Pre-trained on ImageNet-1k (1.28M images, 1000 classes)

Transfer Learning: Initialized with ImageNet weights, preserving low-level edge/texture detectors relevant for medical imaging.

CBAM Attention Module

Sequential Attention: Refines features through two sequential sub-modules operating on different dimensions.

Channel Attention:

  • Aggregates spatial info via global max + average pooling
  • Shared MLP with reduction ratio r=16
  • Outputs channel-wise weights via sigmoid activation
  • Emphasizes pneumonia-indicative feature channels

Spatial Attention:

  • Aggregates channel info via max + average along channel axis
  • 7×7 convolution generates spatial attention map
  • Highlights pathological regions (infiltrates, consolidation)
  • Provides interpretability through spatial weighting

# CBAM Module Implementation (PyTorch) class CBAM(nn.Module): def __init__(self, channels, reduction=16): super(CBAM, self).__init__() # Channel Attention self.channel_attn = nn.Sequential( nn.AdaptiveAvgPool2d(1), nn.Conv2d(channels, channels // reduction, 1), nn.ReLU(), nn.Conv2d(channels // reduction, channels, 1), nn.Sigmoid() ) # Spatial Attention self.spatial_attn = nn.Sequential( nn.Conv2d(2, 1, kernel_size=7, padding=3), nn.Sigmoid() ) def forward(self, x): x = x * self.channel_attn(x) # Channel refinement x = x * self.spatial_attn(x) # Spatial refinement return x

Parameter Efficiency Analysis

DenseNet121+CBAM achieves 8M parameters (31% of ResNet50's 25.6M) while maintaining superior AUC performance (0.9275 vs 0.9137). The CBAM module adds negligible parameters (~50k) while providing significant performance gains (+1.4% AUC) through attention-based feature refinement. This efficiency is critical for deployment on resource-constrained clinical devices.

04 · Training Methodology

Optimization Strategy

A carefully designed training protocol combining focal loss for class imbalance, progressive unfreezing for transfer learning, and threshold optimization for clinical deployment.

Phase 1: Feature Extractor Freezing

Epochs 1-5: Freeze DenseNet121 backbone, train only CBAM and classifier head

  • Rationale: Preserve ImageNet features (edges, textures) while adapting attention to medical domain
  • Learning Rate: 1e-4 for trainable layers
  • Optimizer: AdamW with weight decay 1e-4
  • Batch Size: 16 (constrained by CPU memory)
Phase 2: Progressive Unfreezing

Epochs 6-30: Unfreeze all layers with discriminative learning rates

  • Backbone LR: 1e-5 (lower to prevent catastrophic forgetting)
  • CBAM/Head LR: 1e-4 (higher for faster task adaptation)
  • Scheduler: ReduceLROnPlateau (patience=5, factor=0.5)
  • Early Stopping: Patience=10 epochs on validation loss
Focal Loss Configuration

Formula: FL(pₜ) = -αₜ(1-pₜ)^γ log(pₜ)

  • α=0.75: Weight for normal class (counterbalancing 3:1 imbalance)
  • γ=2.0: Focusing parameter reducing loss for confident predictions
  • Effect: Down-weights easy pneumonia examples, up-weights hard normal examples
  • Compared to BCE: +2.8% improvement in normal class recall
Threshold Optimization (Youden Index)

Post-training calibration: Find optimal decision threshold τ* on validation set

  • Youden Index: J(τ) = Sensitivity(τ) + Specificity(τ) - 1
  • Optimal Threshold: τ* = 0.38 (vs default 0.5)
  • Impact: +3.4% sensitivity improvement with minimal specificity trade-off
  • Clinical Justification: Lower threshold prioritizes detecting true pneumonia cases

Hyperparameter Configuration

  • Optimizer: AdamW (β₁=0.9, β₂=0.999, ε=1e-8)
  • Weight Decay: 1e-4 (L2 regularization)
  • Learning Rate: 1e-4 (head), 1e-5 (backbone after unfreezing)
  • Batch Size: 16 (CPU constraint)
  • Epochs: 30 (with early stopping)
  • Scheduler: ReduceLROnPlateau (factor=0.5, patience=5)
  • Loss Function: Focal Loss (α=0.75, γ=2.0)
  • WeightedRandomSampler: Inverse frequency weights

Computational Environment

  • Hardware: Intel Core i7 CPU (no GPU acceleration)
  • Framework: PyTorch 2.2.0
  • Training Time: ~18 hours for 30 epochs
  • Memory Usage: 8GB RAM (peak during backprop)
  • Limitations: Batch size restricted to 16, no mixed-precision training
  • Future Work: GPU-based training would enable larger batches and faster hyperparameter search
# Focal Loss Implementation (PyTorch) class FocalLoss(nn.Module): def __init__(self, alpha=0.75, gamma=2.0): super(FocalLoss, self).__init__() self.alpha = alpha self.gamma = gamma def forward(self, inputs, targets): BCE_loss = F.binary_cross_entropy_with_logits( inputs, targets, reduction='none' ) pt = torch.exp(-BCE_loss) # Probability of correct class # Apply focal modulation focal_weight = (self.alpha * targets + (1 - self.alpha) * (1 - targets)) * \ ((1 - pt) ** self.gamma) focal_loss = focal_weight * BCE_loss return focal_loss.mean() # Progressive Unfreezing Schedule def unfreeze_strategy(model, epoch): if epoch < 5: # Phase 1: Freeze backbone for param in model.densenet.parameters(): param.requires_grad = False else: # Phase 2: Unfreeze all with discriminative LR for param in model.densenet.parameters(): param.requires_grad = True

Confusion Matrix Analysis

Test set performance (n=624, threshold τ=0.38):

  • True Positives (TP): 375 / 390 pneumonia cases correctly identified
  • False Negatives (FN): 15 / 390 missed pneumonia cases (3.8% miss rate)
  • True Negatives (TN): 147 / 234 normal cases correctly identified
  • False Positives (FP): 87 / 234 normal cases misclassified (37.2% false alarm rate)

Clinical Interpretation: High sensitivity (96.2%) prioritizes detecting true pneumonia cases, accepting moderate false positive rate. In clinical practice, false positives trigger confirmatory testing (blood work, CT scan), while false negatives risk delayed treatment.

Statistical Significance Testing

McNemar's test comparing DenseNet121+CBAM vs DenseNet121 (vanilla) on paired predictions: χ²=8.74, p=0.0031 (p<0.05). The performance improvement is statistically significant at 95% confidence level, confirming that CBAM's contribution is not due to random variance. 06 · Model Interpretability

Grad-CAM Visualizations

Spatial explainability through Gradient-weighted Class Activation Mapping (Grad-CAM), revealing which image regions contribute most to pneumonia predictions.

Grad-CAM Methodology

Algorithm: Generate heatmap H by computing weighted sum of final convolutional layer activations A^k, where weights w^k are gradients of class score y^c with respect to activations.

Formula: H = ReLU(Σ_k w^k · A^k), where w^k = (1/Z) Σ_i Σ_j (∂y^c / ∂A^k_ij)

  • Layer Selection: Final DenseBlock output (1024 channels, 7×7 spatial)
  • Upsampling: Bilinear interpolation to 224×224 for overlay
  • Normalization: Min-max scaling to [0,1] range
  • Visualization: Jet colormap overlaid on grayscale input

Clinical Insights from Heatmaps

Successful Localizations:

  • Model correctly attends to consolidation regions (opaque lung tissue)
  • Highlights infiltrates (patchy abnormalities) in lower lobes
  • Focuses on interstitial patterns (reticular opacities)
  • Ignores non-pathological structures (ribs, mediastinum, diaphragm)

Failure Modes Identified:

  • Artifact Sensitivity: 12% of false positives due to imaging artifacts (motion blur, poor positioning)
  • Peripheral Blind Spots: 8% missed subtle peripheral infiltrates
  • Overlap Confusion: 5% misclassifications when consolidation overlaps with cardiac silhouette

Failure Mode Taxonomy

Category 1: Imaging Artifacts (47% of errors)

  • Motion blur from uncooperative pediatric patients
  • Suboptimal positioning (rotated, underexposed)
  • Equipment-related artifacts (grid lines, edge enhancement)

Category 2: Subtle/Atypical Presentations (38% of errors)

  • Mild, early-stage pneumonia with minimal opacity
  • Peripheral infiltrates at lung periphery
  • Retrocardiac (behind heart) consolidations

Category 3: Anatomical Overlaps (15% of errors)

  • Thymus shadow mimicking infiltrate in young children
  • Consolidation overlapping with cardiac silhouette
  • Crowded mediastinum obscuring pathology
# Grad-CAM Implementation (PyTorch) def generate_gradcam(model, input_tensor, target_class): # Forward pass and store activations activations = [] def hook_fn(module, input, output): activations.append(output) handle = model.densenet.features.register_forward_hook(hook_fn) output = model(input_tensor) handle.remove() # Backward pass to get gradients model.zero_grad() output[0, target_class].backward() gradients = activations[0].grad weights = gradients.mean(dim=[2, 3], keepdim=True) # Weighted sum of activations cam = (weights * activations[0]).sum(dim=1, keepdim=True) cam = F.relu(cam) # ReLU to focus on positive contributions cam = F.interpolate(cam, size=(224, 224), mode='bilinear') # Normalize to [0,1] cam = (cam - cam.min()) / (cam.max() - cam.min()) return cam

Explainability Limitations & Future Directions

Grad-CAM provides coarse spatial localization (7×7 resolution before upsampling) but lacks pixel-wise precision. Advanced techniques like Grad-CAM++ (improved gradient weighting) or Attention Rollout (for ViT architectures) could provide higher-resolution saliency maps. Additionally, integrating segmentation masks from radiologist annotations would enable quantitative evaluation of localization accuracy, moving beyond qualitative visual inspection.

07 · Conclusion & Future Work

Summary & Outlook

Seven mutually reinforcing contributions establish a new state-of-the-art for lightweight, explainable pneumonia detection from pediatric chest X-rays.

Key Contributions

  • [1] CBAM sequential attention within DenseNet121 for binary chest X-ray classification
  • [2] Dual-level class imbalance handling: Focal Loss (α=0.75, γ=2.0) + WeightedRandomSampler
  • [3] Two-phase progressive unfreezing preserving ImageNet pre-trained features
  • [4] Threshold optimization via Youden Index for clinically validated operating point
  • [5] Parameter efficiency: superior AUC at 31% of ResNet50 parameter cost (8M vs 25.6M)
  • [6] Structured Grad-CAM failure-mode taxonomy (3 clinically relevant categories)
  • [7] Rigorous multi-baseline comparative evaluation under identical experimental settings

Acknowledged Limitations

  • Dataset limited to pediatric patients (1-5 years) from single Chinese institution
  • Binary classification only; no bacterial vs viral pneumonia distinction
  • CPU hardware constrains batch size and hyperparameter exploration
  • Grad-CAM provides coarse spatial localization without pixel-wise segmentation
  • No external validation on adult cohorts or different imaging protocols
  • 37.2% false positive rate may strain clinical workflow in low-prevalence settings
Multi-Institutional Validation

Evaluate on diverse cohorts (adult patients, multiple ethnicities, different equipment manufacturers) to assess generalizability beyond single pediatric dataset. Partner with hospitals in North America, Europe, and Africa for multi-site clinical trials.

Multi-Class Extension

Extend from binary to multi-class classification: normal, bacterial pneumonia, viral pneumonia, and COVID-19 pneumonitis. Requires reannotation of dataset by radiologists with pathology-confirmed ground truth.

Vision Transformer Integration

Evaluate Vision Transformer (ViT) and hybrid CNN-ViT architectures (e.g., Swin Transformer, CoAtNet). Transformers may capture long-range dependencies better than CNNs, potentially improving detection of diffuse infiltrates.

Clinical Metadata Integration

Augment imaging with auxiliary clinical variables: patient age, oxygen saturation (SpO₂), fever duration, white blood cell count. Multi-modal fusion could improve diagnostic accuracy beyond image-only models.

Model Deployment & Optimization

Convert to ONNX format and optimize with TensorRT for deployment on mobile devices and edge hardware. Target: <100ms inference latency on smartphone-grade processors for point-of-care screening in resource-limited settings.

Enhanced Explainability

Implement Grad-CAM++ for higher-resolution attention maps and Layer-wise Relevance Propagation (LRP) for pixel-wise attribution. Validate localization accuracy against radiologist-annotated segmentation masks.

Impact Statement

This work demonstrates that attention-augmented CNNs can achieve clinical-grade pneumonia detection with significantly fewer parameters than standard architectures, making deployment feasible on resource-constrained devices. The 96.2% sensitivity meets the threshold for triage tools in low-resource settings, where the cost of missing a pneumonia case far exceeds the cost of unnecessary follow-up testing. By combining quantitative performance metrics with qualitative explainability analysis, we provide a template for responsible AI development in medical imaging—balancing accuracy, efficiency, and interpretability in a manner conducive to clinical adoption and regulatory approval.
